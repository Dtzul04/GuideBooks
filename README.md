# GuideBooks

**Live demo:** (coming soon)

A developer reference tool to sharpen your coding knowledge — built for new and experienced developers alike.

Browse concepts, quiz yourself, and follow a learning roadmap to your choosing across the most important technologies in modern web development.

## Features

- **Reference Library** — Browse categories and topics with clear explanations and code examples
- **Quick Quiz** — Test your knowledge with randomized questions per topic
- **Roadmap** — Visual learning paths to guide your next steps as a developer

## Tech Stack

| Layer | Tech |
|-------|------|
| Frontend | Next.js, React, TypeScript |
| Styling | Tailwind CSS |
| Deploy | Vercel |

## Categories

- **Languages** — HTML5, CSS3, JavaScript (ES6+), TypeScript, Python, SQL, PostgreSQL, Markdown

- **Frameworks & Libraries** — React, Next.js, Node.js, Express, Tailwind CSS, Vite

- **Tools & Workflow** — Git, GitHub, VS Code, Terminal/Linux, Docker basics, Postman, Vercel, Render

- **AI & APIs** — REST APIs, JWT Authentication, Google Gemini, OpenAI, Groq, API Integration patterns

- **Concepts & Patterns** — Algorithms, Data Structures, Sliding Window, Two Pointers, Hash Maps, Big Notation, SOLID Principles, Clean Code

- **DevOps & Deployment** — GitHub Actions, CI/CD, Environment Variables, Vercel, Render, Docker basics

- **Database** — PostgreSQL, SQL queries, CRUD operations, Supabase, MongoDB basicss

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
