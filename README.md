A developer reference tool to sharpen your coding knowledge — built for new and experienced developers alike.

Browse concepts, quiz yourself, and follow a learning roadmap across modern web development.

## Features

- **Reference Library** — Browse categories and topics with summaries and code examples
- **Quick Quiz** — Pick a category, topic, and lesson; shuffled options with green/red feedback
- **Roadmap** — Frontend, Backend, and Full Stack learning paths

## Tech Stack

| Layer | Tech |
|-------|------|
| Frontend | Next.js, React, TypeScript |
| Styling | Tailwind CSS |
| Deploy | Vercel |

## Categories

- **Languages** — JavaScript, TypeScript, HTML & CSS, Python, SQL
- **Frameworks** — React, Next.js, Node.js, Express.js, Tailwind CSS
- **Tools** — Git, Terminal/Linux, VS Code, GitHub
- **AI & APIs** — REST APIs, JWT Authentication, Google Gemini API, API Integration
- **Concepts** — Algorithms, Data Structures, Clean Code, SOLID Principles
- **DevOps** — GitHub Actions, Docker (basics), Deployment
- **Databases** — PostgreSQL, SQL Queries, MongoDB (basics)

## Getting Started

```bash
npm install
npm run dev
```
